Por qué existe

Una ferretería le debe a un distribuidor, el distribuidor le debe a un transportista y el transportista le debe a la ferretería. Las tres creen tener un problema de caja. Lo que tienen es un problema de información. QUADRA dibuja el mapa completo y hace visible la deuda que se anula sola.
